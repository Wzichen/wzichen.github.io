### ⚡ 快速安装指南

#### 基础安装步骤

DeepXDE提供多种安装方式，满足不同用户需求：

**PyPI快速安装**：

```bash
pip install deepxde
```

**Conda安装**：

```bash
conda install -c conda-forge deepxde
```

**源码安装**：

```bash
git clone https://gitcode.com/gh_mirrors/de/deepxde

cd deepxde

pip install .
```

#### 后端配置方法

安装完成后，通过环境变量选择后端：

```bash
DDE_BACKEND=pytorch python your_script.py

DDE_BACKEND=tensorflow python your_script.py
```

也可通过配置文件永久设置默认后端：

```bash
python -m deepxde.backend.set_default_backend pytorch
```

### 🔍 核心模块与使用示例

#### 问题定义流程

使用DeepXDE求解PDE问题通常遵循以下步骤：

1. 定义几何区域（通过[deepxde/geometry/](https://link.gitcode.com/i/126a88014a5298b5e291e67bb2306d69)）
2. 定义PDE方程和边界条件（通过[deepxde/icbc/](https://link.gitcode.com/i/0c649c2c79c089391f4df8d0d68705eb)）
3. 创建数据集和数据加载器
4. 构建神经网络模型
5. 训练与评估

#### 一维Poisson方程求解示例

以下是使用DeepXDE求解简单PDE的示例代码：

```python
import deepxde as dde

import numpy as np

def pde(x, y):

dy_xx = dde.grad.hessian(y, x)

return -dy_xx - np.pi**2 * np.sin(np.pi * x)

geom = dde.geometry.Interval(-1, 1)

def boundary(x, on_boundary):

return on_boundary

bc = dde.DirichletBC(geom, lambda x: 0, boundary)

data = dde.data.PDE(geom, pde, bc, num_domain=100, num_boundary=2)

net = dde.nn.FNN([1] + [50] * 3 + [1], "tanh", "Glorot normal")

model = dde.Model(data, net)

model.compile("adam", lr=0.001, metrics=["l2 relative error"])

losshistory, train_state = model.train(epochs=10000)

dde.saveplot(losshistory, train_state, issave=True, isplot=True)
```
